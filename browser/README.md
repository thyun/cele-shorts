# Chrome 브라우저 자동화

프로젝트 루트에서 `npm install`을 실행한 뒤 `npm run browser:open`으로 Chrome과 YouTube Studio를 연다. 별도의 `.browser-profile/`에 로그인 세션을 보관하므로, 처음에는 브라우저에서 직접 Google 계정으로 로그인한다. 인증 코드나 비밀번호를 채팅에 입력하지 않는다. 종료하려면 Chrome 창을 닫는다.

`npm run browser:check`는 로그인 없이 별도의 헤드리스 Chrome에서 로컬 테스트 페이지를 열어 자동화 연결을 확인한다.

`.browser-profile/`에는 인증 정보가 포함될 수 있으므로 공유하거나 Git에 올리지 않는다. 기존 Chrome 프로필은 사용하지 않는다. Google이 자동화 브라우저의 로그인을 제한할 수 있으며, 이 경우 우회하지 말고 정상적으로 지원되는 인증 방법을 사용한다.

이 설정은 별도의 브라우저 제어 도구를 대화에 연결하는 것이 아니라, 이후 Playwright 스크립트로 Chrome을 제어할 수 있도록 준비한 것이다. 다른 자동화 스크립트에서 같은 프로필을 사용하기 전에는 열린 자동화 Chrome 창을 닫아야 한다.

이 명령은 업로드하지 않는다. 업로드 자동화도 아직 구현되지 않았다. 실제 업로드 전에는 권리와 제휴 표시를 확인하고, 대상 영상·채널·제목·공개 범위를 사용자가 확인해야 한다.
